# Deferred project sources

## 500 Tower Defense

`sunpole/500` is deliberately excluded from automatic uNews discovery.
The project is postponed; its repository, history, and publication state are
not deleted or changed by this decision.

The exclusion prevents an unavailable source from blocking unrelated project
news. Before re-enabling it, the owner must verify the intended public
repository and branch, then restore it through a separate small patch with a
full `publish:all:check` run.
