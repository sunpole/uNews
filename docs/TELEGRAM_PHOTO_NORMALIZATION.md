# Telegram photo normalization / Нормализация фото для Telegram

## Причина

Telegram `sendPhoto` принимает фото не больше 10 МБ, с суммой ширины и высоты не больше 10000 px и отношением сторон не больше 20:1.

uNews обязан сохранять исходные изображения проектов как исторические доказательства. Поэтому длинный Chromium screenshot не заменяется и не перезаписывается в исходном репозитории.

## Порядок обработки

1. uNews скачивает исходный файл через GET.
2. Проверяет расширение и реальные bytes.
3. Проверяет PNG signature, chunks, CRC, zlib stream, dimensions и отсутствие trailing bytes.
4. Если фото уже безопасно для Telegram, тот же Buffer отправляется byte-for-byte.
5. Если PNG превышает размер или сумму сторон, создаётся временная копия только в памяти.
6. Копия сохраняет пропорции и получает безопасную сумму сторон не больше 9800 px.
7. Копия повторно проходит полный image-integrity validator.
8. Telegram получает только проверенный Blob временной копии.
9. Исходный файл и исторический архив не меняются.

## Поддержанный автоматический формат

Автоматически нормализуются:

- PNG;
- bit depth 8;
- RGB или RGBA;
- без interlace.

Если oversized-файл имеет другой формат или неподдерживаемую структуру, публикация блокируется до Telegram с понятной ошибкой. uNews не выполняет скрытое преобразование сомнительного изображения.

## Алгоритм

- PNG IDAT распаковывается через zlib;
- фильтры строк 0–4 восстанавливаются;
- изображение уменьшается nearest-neighbour с сохранением отношения сторон;
- новый PNG кодируется с filter 0;
- chunks получают новый CRC;
- результат повторно проверяется тем же валидатором.

## Regression fixtures

### Длинный M4 screenshot

```text
source: 1440 × 8625
sum:    10065
result: normalized PNG with sum <= 9800
```

Проверяется:

- source Buffer не изменён;
- output меньше 10 МБ;
- output проходит deep validation;
- отношение сторон сохранено.

### Безопасный M6 screenshot

```text
source: 1180 × 1189
sum:    2369
```

Он остаётся byte-for-byte неизменным.

## Граница

Нормализация создаёт только Telegram delivery copy. Она не является редактором исходных изображений и не меняет файлы проектов, release assets или архивы.
