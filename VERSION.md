# uNews 0.3.10

Текущая версия: `0.3.10` — uNews исправляет следующую фактическую проблему очереди, найденную после восстановления `documentation`:

- `type: audit` теперь принимается как безопасный аудиторский отчёт.

## Что исправлено

### Тип `audit`

До `0.3.10` policy-слой поддерживал `report`, `docs` и `documentation`, но не поддерживал отдельный тип `audit`. Из-за этого патчноут `uDream 23.8.10` блокировался ошибкой:

```text
Unsupported type: audit
```

Теперь `audit` разрешён и получает собственное поведение: если короткий Telegram-текст не содержит слов “аудит” или “отчёт”, policy добавляет компактную вводную фразу:

```text
Аудит.
```

## Регрессия

Добавлена отдельная проверка `scripts/check-audit-policy.js`:

- `type: audit` проходит policy-слой;
- подпись получает автоматический префикс `Аудит.`, если в тексте нет audit/report wording;
- подпись не дублирует слово “Аудит”, если автор уже написал его сам;
- сохраняются обязательные хештеги проекта `uDream`.

`npm test` теперь запускает эту проверку через `npm run check:fixtures`.

## Не изменено

- строгий FIFO и порядок версий внутри проекта;
- максимум 20 публикаций за запуск;
- пауза не менее 61 секунды;
- фильтр `YYYY-MM-DD-*.md` для файлов в `news/`;
- поддержка `type: documentation` из `0.3.9`;
- image integrity проверка через GET, CRC, zlib и повторную проверку перед Telegram;
- Telegram-safe PNG normalization из `0.3.8`;
- secret redaction и запрет реальной локальной публикации.
